## 1. Scope and claim

The paper evaluates one claim: a language standard can provide the maintained
source for a mechanically generated syntax representation, provided that the
representation keeps provenance and reports where the source is insufficient
for a target parser. The claim concerns syntax extraction, projection and a
bounded source-controlled semantic-evidence boundary. It does not include
semantic constraint rule bodies, a complete parser, or a compiler.

The primary source is J3/24-007, a freely downloadable Fortran 2023 working
draft. The artifact is identified by SHA-256 in `artifacts/standards/` and is
fetched into an ignored cache by `scripts/fetch.sh`. The extraction target is
the numbered syntax span in the document. StandardIR is the canonical
intermediate representation. EBNF, ANTLR4, Bison, and tree-sitter are derived
exports, not maintained sources.

The closest prior work is semi-automatic grammar recovery from manuals and
compiler artifacts [2]. That work combines extraction, correction, testing and
modularization. This paper measures a narrower boundary: numbered syntax from
a pinned standards document, per-record provenance, deterministic target
projection, and the first generated parser operations over real Fortran files.
The Fortran context is surveyed by Kedward et al. [3].

## 2. Method

### 2.1 Source boundary

`standard-new` extracts PDF bytes, text rectangles, and a canonical text view.
Each syntax object retains its source document, clause, rule number, page,
span, and source hash. The extraction policy preserves undecided layout cases
as evidence. D0020 permits extraction of other pages while an ambiguous page
remains unavailable for authoritative use. This keeps a local document defect
from silently changing unrelated records.

### 2.2 StandardIR and projections

The syntax extractor recognizes numbered productions and continuation lines,
then writes canonical StandardIR SX. A byte-identical SX round-trip is checked
before projection. Each target emitter consumes the same ordered syntax records
and writes target-specific syntax. Comments in every export carry the source
rule and provenance hash.

Repeated left-hand sides are grouped only in the derived parser input. D0018
therefore distinguishes raw syntax exports from a composite parser input. D0019
defines the next representation boundary: lexical classes, aliases,
metavariables, semantic roles, unresolved terms, and disputed terms are typed
source-provenanced resolution records. A parser alias is a projection of such a
record and cannot become a second maintained truth. The reported D0019 slice
applies this policy to source-controlled witnesses and preserves the remaining
unresolved terms in the same record table. The R402 closure then applies the
same source rule to every absent term whose spelling ends in `-name`, after an
independent check for explicit StandardIR definitions.

and quotation marks unresolved under D0020.

### 2.3 Verification

The experiments use independent structural traversals, fixed witnesses, target
tool validators, and behavioral comparison against LFortran, Flang, and
gfortran. The gfortran source is not consulted. Its binary behavior is used as
a GPL-compatible oracle under the repository's clean-room rule. Failed
validation is retained as an accepted experiment result when it identifies a
known boundary rather than an implementation accident.

## 4. Interpretation

The extraction result establishes a useful separation. Numbered syntax can be
recovered from the pinned document and represented with source identity without
asking a model to invent grammar. The four target projections agree with the
same ordered StandardIR input at the structural level. This is evidence for a
mechanical syntax projection, not evidence that the target grammars accept all
Fortran programs.

The failed target validation is the central limitation and a useful result.
The complete-core syntax span contains references whose definitions are not
available as parser productions in that projection. Replacing every such name
with `name` would erase distinctions between lexical classes, syntax
metavariables, and semantic role names. Copying aliases from a comparison
grammar would violate the source boundary. The recorded unresolved inventory
therefore defines the next experiment rather than disappearing into a guessed
grammar. The D0019 slice supplies a source-controlled alias projection while
retaining unresolved records. It is evidence for the resolution record contract,
not completion of the composite parser input. The R402 closure expands the

## 5. Reproducibility and limitations

The paper package pins its run IDs, source hash, and generator commits. Run
records are append-only. The analysis script verifies that every selected run
exists exactly once, checks the source identity, checks the expected accepted
failure, and writes the results and manuscript. The external PDF and grammar
sources are never vendored.

The study uses one Fortran working draft and one selected syntax span. It does
not measure parser throughput, complete semantic coverage, diagnostic quality,
or model cost. The grammar exports are syntax projections. The E0090 and E0091
slices evaluate C601 and C719. E0092 supplies one generic evaluator for C601,
C603 and C719. E0093 supplies a structured diagnostic operation around that
evaluator. E0095, E0096 and E0097 extend execution to bounded nested and
finite-domain forms. The remaining accepted predicates are table data rather
than evaluated semantics. The comparison corpus is evidence for adjudication
and not a normative input.
