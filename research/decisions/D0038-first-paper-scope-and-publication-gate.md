# D0038. First paper scope and publication gate

Date: 2026-08-13
Status: accepted
<!-- proposed | accepted | superseded by D#### | amended by D#### | retracted -->

## Context

The laboratory already has a reproducible first result. The pinned J3/24-007
document yields 522 numbered syntax productions, four grammar projections, a
direct-parser wiring slice, source-linked local parser operations, and a
source-controlled semantic ledger. E0069 through E0078 measure the mechanical
normative-prose boundary. E0089 through E0097 measure bounded semantic formalization
and generic evaluation. The manuscript and its rendered PDF are regenerated
from append-only run records.

The production `fortfront-new` repository has not been created. Waiting for a
complete frontend would leave the demonstrated laboratory result unpublished
and would mix a later engineering gate into the first scientific claim.

## Decision

Publish the first paper as a venue-neutral artifact paper about the
standard-to-grammar boundary. Its supported claims are:

- a pinned Fortran standard can be converted into provenance-preserving
  StandardIR syntax records with 522/522 numbered production starts;
- one source representation can drive EBNF, ANTLR4, Bison, tree-sitter and
  direct-parser projections with deterministic wiring;
- source-controlled resolution records expose lexical, metasyntactic and
  semantic residue instead of guessing parser aliases;
- bounded semantic rules can enter a generated rule table and generic
  evaluators while retaining source-linked diagnostics and independent oracle
  checks.

The publication gate is the committed manuscript generated by
`papers/standard-to-grammar/analyse.sh`, the rendered PDF from
`papers/standard-to-grammar/render.sh`, the pinned run and artifact ledgers,
and passing repository quality gates. The paper must state that it does not
claim a complete Fortran parser, complete semantic coverage, throughput, a
compiler, or production `fortfront-new` integration.

`fortfront-new`, full semantic coverage, performance comparison and
compilation remain follow-up work. They must not block submission of this
first paper.

## Rejected

Holding the paper until `fortfront-new` exists is rejected because the
production repository is a separate project boundary and is currently absent.
Claiming a complete parser from the generated facade is rejected because the
current witnesses establish only bounded operations over declared corpora.
Removing unresolved and failed runs is rejected because it would erase the
measured boundary and the denominator.

## Reversal condition

Write a successor if an independent audit finds that the pinned manuscript
does not reproduce its reported results, if a target venue requires a complete
frontend as a condition of this specific claim, or if independent reviewers
show that the stated syntax and provenance contribution is already established
by a materially equivalent prior artifact. A request for more future work is
not by itself a reason to widen this first paper.
