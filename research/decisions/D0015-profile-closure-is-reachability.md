# D0015. Profile closure is reachability, not feature support

Date: 2026-08-12
Status: accepted

## Context

The E0014 result is regenerated by
`research/experiments/E0014-core0-profile/check-core0-closure.sh`. Its declared
Core 0 roots resolve to a mechanical syntax closure, but the standard uses
broad aggregate productions. The closure therefore reaches syntax for features
that the prose profile initially excludes, including block data, statement
functions, assigned and computed transfer, FORMAT machinery, coarrays and
polymorphic constructs. The same run retains unresolved reference names rather
than mistaking punctuation conventions for rules.

## Decision

Keep the complete StandardIR dependency graph as normative reachability data.
Treat a user profile as two explicit layers:

1. a positive root set and its mechanically computed rule-ID closure; and
2. a separately derived feature-eligibility projection that can prune
   alternatives only when the resulting references remain closed.

E0014 is therefore a syntax-closure result, not a claim that `core0-v1` already
has the intended semantic exclusions. The next profile gate must classify
unresolved references and prove that any pruning preserves a closed generated
grammar. No rule is deleted from the source corpus to make a profile appear
smaller.

## Rejected

**Call the positive closure Core 0 support.** That would silently include
features the whitepaper excludes and would confuse grammar reachability with
implemented language semantics.

**Delete unresolved references.** Some are terminal notation conventions, but
deleting them loses evidence and makes the dependency result non-auditable.

**Edit the normative syntax records into profile-specific rules.** That would
destroy the one source corpus shared by Core 0, later profiles and full F2023.

## Reversal condition

If a later StandardIR profile formalization shows that aggregate productions
are already feature-factored by a normative rule the current graph failed to
represent, a successor decision may replace the projection step with that
explicit rule relation. The original E0014 graph and this decision remain
historical evidence.
