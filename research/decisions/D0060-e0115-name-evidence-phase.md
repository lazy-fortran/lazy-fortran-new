# D0060 — Close the source-backed name/evidence phase

Status: accepted
Date: 2026-08-14
Supersedes: D0059 (operational result; the boundary remains in force)

## Decision

The E0115 source-backed name/evidence phase is complete. The deterministic
closure remains authoritative: it covers all 127 residue rows with zero model
calls. The local LLM is retained only as a bounded evidence navigator and
pointer submitter. Its output is accepted only through the existing source,
provenance and behavioral gates.

Use one bounded retry for incomplete candidate names when measuring model
convergence. Preserve the first pass, retry rows, failures and timings. Do not
add candidate-specific mechanical branches to rescue a model.

The next phase is a small typed semantic predicate pilot, beginning with a
source-backed rule such as C702, where the model may propose a local predicate
but the deterministic schema and behavioral oracle decide whether it is
admissible.

## Rejected alternatives

- Give every clause to an LLM and accept prose descriptions.
- Let a model invent citations, targets, semantic facts or compiler wiring.
- Add special-case mechanical branches for each failed candidate.
- Treat abstention as success or remove failed rows from the denominator.

## Reversal condition

Reverse this boundary only if the typed-predicate pilot shows that the source,
schema and behavioral gates cannot distinguish a valid local predicate from a
plausible but unsupported one, or if a supposedly generic normalizer requires
more rule text than implementation logic for a repeated source form.
