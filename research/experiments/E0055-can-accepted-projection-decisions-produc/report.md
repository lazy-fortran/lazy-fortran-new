# E0055. Accepted deterministic projections and composite parser validation

Generated by `research/experiments/E0055-can-accepted-projection-decisions-produc/analyse.sh`.

## Question

Can the accepted D0024, D0026 and D0027 projections produce target-valid
composite parser inputs?

## Method

The analysis reruns E0049 and E0053, applies the fixed D0025 token operations,
removes the three source-level R401/R402/R403 templates from the target input,
and lowers the 80 R401 and 20 R403 family records. R401 becomes an explicit
comma-separated repetition. R403 becomes a base reference with a retained C401
fact. The three D0026 overlap terms carry both facts and are lowered after the
errata operation.

The target-independent D0027 schema contains the three accepted lexical
classes and two unresolved Unicode records. ANTLR4, Bison and tree-sitter
receive deterministic adapters from that same schema. The `rep-char` adapter
remains symbolic because the source defines its character set as processor
dependent.

## Result

The projection phase passes. It emits 519 target syntax records from the 522
source records, 100 typed expansion records, 3 compositional overlap records,
and 5 lexical schema records. The generated target diagnostics contain zero
unresolved ANTLR4 or Bison names.

Target generation still fails at a separate structural boundary:

| Target | Exit status | Boundary |
|---|---:|---|
| ANTLR4 | 1 | Existing empty-alternative warnings are fatal under `-Werror`, and mutual left recursion remains |
| Bison | 1 | Existing useless-nonterminal and conflict diagnostics are fatal under `-Werror` |
| tree-sitter | 1 | Existing empty-string rule `r_specification_x2D_part` is unsupported |

The result is therefore `verification_failure_structural_target`, not a
failure of the accepted source-resolution projection. No model calls were
made. The controlled expansion-family mutation fails as required.

## Boundary

D0024, D0026 and D0027 now have executable deterministic projections. The next
work slice is target grammar normalization: eliminate or represent the
pre-existing empty-rule, left-recursion and conflict boundaries without
changing StandardIR or asking an LLM to wire the grammar.
