## Question

Can continuation-aware deterministic normalization formalize longer referenced
constraints while retaining an implicit-typing residue?

## Method

The analyzer reruns the E0081 constraint inventory over the pinned J3/24-007
canonical text. It joins line continuations by removing extracted line
numbers, joining hyphenated words, and collapsing whitespace. Six policy rows
then select longer constraints with alternatives, referenced clauses or
cross-scope conditions.

Five rows receive normalized predicates with subjects, applicability, required
facts and provided facts. C1588 remains `unresolved` because the current fact
vocabulary cannot represent implied type parameters and the extracted
two-column source does not provide one contiguous evidence witness for the
full sentence. The other 281 inventory records also remain unresolved.

The independent oracle checks statuses, source phrases for resolved rows,
predicates and fact sets. A dependency graph is checked against its
topological order. A continuation-source mutation and a predicate mutation
must fail.

## Boundary

E0085 validates continuation-aware normalization and exercises a real
`unresolved` outcome in the selected policy. It does not yet exercise a
`disputed` outcome because the independent formalizers agree on every selected
resolved predicate. The next slice should introduce a deliberately competing
formalization only where the normative wording supports both readings, or
expand the fact vocabulary if an independent adjudication shows that the
implicit-typing rule can be represented without hidden phase assumptions.
