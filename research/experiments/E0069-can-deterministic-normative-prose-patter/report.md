# E0069 report

All values and evidence tables below are regenerated by
`research/experiments/E0069-can-deterministic-normative-prose-patter/analyse.sh`.
The recognizer is pinned to `lazy-fortran-new` commit `37c07db`, the canonical
text and E0022 audit are pinned by SHA-256, and the run makes no model calls.

## Question

Can exact normative-prose patterns classify part of the 181-name unresolved
StandardIR reference denominator before any model escalation?

## Method

The analysis scans the complete canonical text line by line. It retains every
E0022 term, derives the document page from form-feed boundaries, and records a
candidate only for one of four exact forms:

- a lexical-class definition (`defines the syntactic class` or `is one of`);
- the assumed-rule metavariable declaration for `xyz`;
- a same-line name-role relation (`the name of ... is <term>` or
  `<term> is the name of`);
- a direct alias form (`<term> is name`, `<term> is a name`, or
  `<term> is an identifier`).

Candidates are evidence records with source hash, canonical line and page.
They are not StandardIR facts and are not projected into a parser. A separate
grep/awk traversal recomputes the candidate set. The fixed witness table checks
two lexical definitions, the metanotation declaration, one semantic-role
sentence and a negative `program-name` case. A controlled mutation removes the
`digit` lexical marker and must fail the witness gate.

The lexical candidates are `letter` and `digit`. The metanotation candidate is
`xyz`. The semantic-role candidates are `module-name`, `function-name`,
`result-name` and `subroutine-name`. No direct alias was recovered from these
exact prose forms. The recognizer intentionally does not join a relation across
canonical lines; that residue remains available for a later sentence-structure
experiment rather than being guessed here.

## Boundary

This run measures a useful but small mechanical fraction: 7 of 181 names have
at least one exact candidate span, and none is accepted as StandardIR by this
experiment. The result supports the proposed escalation order. The next
mechanical slice should add bounded sentence and table structure, with fixed
source witnesses and no suffix-based inference. Only after that measured pass
should the remaining residue be offered to a model.
