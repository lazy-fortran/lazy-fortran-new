## Prompt

How well does the E0164 output represent a trustworthy source-backed Fortran
2023 grammar/lexer/runtime gate?

## Adjudication

The result is useful pre-runtime evidence, but not a trustworthy complete
Fortran 2023 grammar/lexer/runtime gate.

| Gate | Verdict | Reason |
|---|---|---|
| Contract row integrity | PASS | Both contracts match; five unique rows have mechanical origin and populated provenance. |
| Source provenance verification | PASS after correction | The adjudicator compares rows with lexical facts and the pinned J3 artifact hash. |
| Generator checks | PASS, smoke only | ANTLR4, Bison and tree-sitter generate; this does not establish language equivalence. |
| Grammar completeness | OPEN | 1,068 source alternatives still yield 1,061 emitted bodies and seven omitted bodies; six declared roots are omitted. |
| Grammar ambiguity | OPEN | Baseline conflicts are 427/2,266 and candidate conflicts are 425/2,135. |
| Lexical spelling mutation | PASS, narrow | The selected five-fact lexical witness passes its mutation; it is not the complete lexer inventory. |
| Bounded language behavior | PASS, narrow | 359 positives and 636 negatives pass the bounded differential recognizer. |
| External behavior | PASS, narrow | Three frontends agree on ten fixtures; this is not a normative oracle. |
| fortfront lexer tests | PASS, narrow | The pinned log reports 24 tests passed; it is not a generated-parser test. |
| Generated parser runtime | OPEN | No executable runtime consumes the generated StandardIR grammar. |

## Recommendation

Keep E0164 open. Do not resume semantic/model work or call the grammar
complete. Integrate an executable generated parser runtime and execution-level
differential tests before accepting this gate.
