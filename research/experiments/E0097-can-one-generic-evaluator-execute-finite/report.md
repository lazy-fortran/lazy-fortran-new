## Question

Can one generic evaluator execute accepted finite-domain predicates over
binary and octal literal witnesses?

## Method

The analysis reruns E0090 and selects C7117 and C7118 from its generated
semantic rule table. Both rows have the same `in` predicate constructor but
different finite literal sets. The generated evaluator reads the digit from a
Fortran DATA statement and interprets the set from the predicate row. It
contains neither selected constraint ID.

The six witnesses cover zero and one for binary constants, zero and seven for
octal constants, and one out-of-domain value for each. GNU Fortran and Flang
independently check the same DATA statements. Accepted and rejected results
retain the StandardIR line, page, source hash and predicate. Replacing the
C7117 set with `(0 2)` is a controlled mutation and must reject the valid
binary witness.
