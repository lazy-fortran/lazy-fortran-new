# E0121: expanded source-oracle finite-case gate

E0121 replays the E0118 finite-case harness with the 23-record source oracle
generated by E0120. It is a successor measurement, not a mutation of the
reported E0118 E0083 run.

Run it with:

```sh
E0118_ORACLE=research/experiments/E0120-can-deterministic-normative-constraint-f/source-oracle.tsv \
E0118_OUTDIR=.cache/runs/E0121/R000001 \
research/experiments/E0118-can-independently-generated-source-deriv/analyse.sh
```

The deterministic source oracle owns case materialization and expected
outcomes. The frozen E0117 proposal is evaluated only as a candidate. If its
fact names cannot be evaluated against the source-derived case, the result is
`candidate_unavailable`; the harness does not invent aliases. Unsupported
source predicate constructors are retained as `oracle_unavailable`.

No compiler is invoked without a faithful fixture, and no semantic fact is
promoted. The run records the full 287-row denominator, all 23 oracle rows,
case outcomes, candidate-unavailable cases, mutation controls and wall time.
