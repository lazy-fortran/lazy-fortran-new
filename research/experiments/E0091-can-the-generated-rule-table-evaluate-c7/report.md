## Method

checks the predicate, required and provided facts, source location, source hash,
source evidence and mechanical origin against a separately maintained target
oracle. It derives the nonnegative bound from the predicate rather than from a
separate implementation constant.

It then generates a C719 checker and runs it against `integer(kind=1)` and
`integer(kind=-1)` witnesses. GNU Fortran independently checks the same two
sources. A separate witness oracle fixes both expected statuses and the source
location. Predicate and source-location mutations are negative controls.
