# E0073 report

All values and target files below are regenerated by
`research/experiments/E0073-can-the-e0072-parser-resolution-sidecar-/analyse.sh`.
The analyzer is pinned to `lazy-fortran-new` commit `c6c6d0e` and makes no
experimental model calls.

## Question

Can the E0072 parser-resolution sidecar emit every target fragment without
projecting semantic facts?

## Method

The analysis reruns E0072 and verifies the composite fact and parser-projection
hashes. It normalizes the 11 parser-targeted records once, then emits small
probes in EBNF, ANTLR4, Bison, tree-sitter and direct Fortran. Each probe keeps
the source term, class, source rule, page and origin in its generated output.
The probes use unique prefixes where a target parser would otherwise collapse
three equivalent alias reductions; those prefixes are validation harness input,
not StandardIR facts.

An independent traversal checks all 55 target provenance instances and scans
the five outputs for the 29 semantic-role records. The target tools validate
their own probes, and a parser-target mutation must change the independent
projection witness.

## Boundary

This validates the resolution sidecar, not the full 522-production parser
input. The next slice should integrate the sidecar with the complete syntax
projection and direct-parser wiring, retaining the 151 unresolved prose names
as an explicit residue.
