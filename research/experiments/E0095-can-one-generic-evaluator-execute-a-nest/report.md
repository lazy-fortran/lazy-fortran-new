## Question

Can one generic evaluator execute a nested `implies` predicate with source
facts?

## Method

The analyzer reruns E0090 and selects C721 from its generated rule table. The
generated evaluator reads facts from three real Fortran sources and interprets
the predicate constructors `implies`, `and`, `present` and `eq` with a small
generic expression interpreter. It emits a source-linked acceptance or
diagnostic record.

The witnesses exercise a true antecedent with a true consequent, a true
antecedent with a false consequent, and a false antecedent. GNU Fortran checks
the same sources. Separate target and witness oracles fix the predicate,
source location and expected outcomes. A predicate mutation is the negative
control.
