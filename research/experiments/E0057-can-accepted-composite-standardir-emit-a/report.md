# E0057. Deterministic direct-parser wiring skeleton

Generated by `research/experiments/E0057-can-accepted-composite-standardir-emit-a/analyse.sh`.

## Question

Can the accepted composite StandardIR input emit a provenance-bearing direct
parser wiring skeleton without target grammar conflict metadata or model calls?

## Method

The analysis reruns E0055 and checks the accepted composite-input hash. It
performs an independent source-driven traversal of the 519 composite syntax
records. Each record becomes one dispatch row containing its left-hand side,
generated procedure name, source rule, source page and source hash. Repeated
left-hand sides share one procedure and retain all source-rule comments.

The emitter then writes a Fortran module with one deterministic dispatch case
and one procedure per unique left-hand side. Procedure bodies are marked as
local implementation holes. The generated module is compiled with
`gfortran -Wall -Wextra -Werror`. A mutation of the first source left-hand side
must change the independent dispatch witness.

## Result

The accepted composite input emits 519 dispatch rows and 499 procedures. Every
row carries source provenance. There are no procedure-label collisions and no
remaining typed unresolved references. The generated Fortran module compiles
with zero warnings under the selected compiler.

| Metric | Value |
|---|---:|

| Composite syntax records | 519 |
| Unique left-hand sides | 499 |

The result is `wiring_skeleton_compiled`. It validates deterministic
composition and source coverage. It does not validate parser behavior because
the procedure bodies remain unresolved local holes.

## Boundary

The experiment establishes the first generated wiring artifact after D0029.
The next implementation must fill typed local parser operations and validate
them against a real source corpus. The dispatch structure, procedure ownership,
ordering and provenance remain generator-owned facts.

No model calls were made. The result follows D0028 and D0029 by generating the
composition directly and leaving only local implementation work unresolved.
