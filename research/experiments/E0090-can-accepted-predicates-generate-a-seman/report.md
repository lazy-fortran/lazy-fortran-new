# E0090 report

All values and evidence below are regenerated by
`research/experiments/E0090-can-accepted-predicates-generate-a-seman/analyse.sh`.
The analyzer makes no experimental model calls.

## Question

Can the 22 accepted predicates in the E0089 successor ledger become a
provenance-bearing semantic rule table, and can one generated rule reject a
real invalid Fortran source while accepting a valid source?

## Method

The analyzer reruns E0089 and projects its resolved formalization records into
a table containing the constraint ID, syntax rule, standard location, source
hash, applicability, fact dependencies, predicate, source evidence and origin.
It derives a dispatch table from the same rows. A separately maintained table
oracle checks every predicate and fact edge.

For C601, the analyzer extracts the bound from the generated predicate and
generates a local checker whose acceptance message and diagnostic retain the
J3/24-007 source location and hash. It runs that checker and gfortran against
one-character and 64-character names. A separate witness oracle fixes both
outcomes and the expected name lengths. The generated table is also subjected
to a predicate mutation.
