# E0093 report

All values and evidence below are regenerated by
`research/experiments/E0093-can-the-generic-evaluator-feed-a-generat/analyse.sh`.
The analyzer makes no experimental model calls.

## Question

Can the generic evaluator feed one generated source-linked diagnostic
operation without moving rule-specific wiring into the operation?

## Method

The analyzer reruns E0092 and checks its summary hash. It generates one
operation around the E0092 evaluator and table. The operation receives a case,
constraint and source path as data. It looks up the selected row, invokes the
generic evaluator, and emits one tab-separated record containing status,
severity, StandardIR line and page, standard source hash, source-file hash,
message and predicate.

The six witnesses are the E0092 positive and negative sources for C601, C603
and C719. A separately maintained diagnostic oracle fixes the expected status,
severity, source location and message. The generated operation is searched for
the selected constraint IDs. A message mutation is the negative control.

All six records agree with the independent diagnostic oracle. Each record
retains both the StandardIR source identity and the concrete witness source
hash. The operation contains no selected rule ID. This validates a structured
diagnostic boundary around the generic evaluator. It does not connect the
operation to the production `fortfront-new` frontend or establish complete
diagnostic behavior.
