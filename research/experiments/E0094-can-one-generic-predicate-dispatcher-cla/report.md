# E0094 report

All values and evidence below are regenerated by
`research/experiments/E0094-can-one-generic-predicate-dispatcher-cla/analyse.sh`.
The analyzer makes no experimental model calls.

## Question

Can one generic predicate dispatcher classify all accepted semantic rule forms
without rule-specific branches?

## Method

The analyzer reruns E0090 and reads its 22-row generated semantic rule table.
The generated dispatcher extracts the top-level constructor from each predicate
and accepts the nine constructors present in the table. It emits the predicate,
constructor, StandardIR line, page and source hash. The dispatcher source is
searched for all selected rule IDs.

A separately maintained 22-row oracle fixes the expected top-level constructor
for every accepted predicate. The analyzer compares the generated output with
that oracle. Replacing the `le` predicate with an unknown constructor is the
negative control.

coverage for the 265 unresolved constraints.
