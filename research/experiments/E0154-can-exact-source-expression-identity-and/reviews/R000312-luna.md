# Luna review of E0154/R000311

Model: gpt-5.6-luna
Mode: read-only
Question: How well does this represent the Fortran 2023 standard?

## Verdict

R000311 is a provenance-rich, source-backed projection of a selected Fortran
2023 syntax profile. It is not yet a faithful representation of the full
standard and is not an LFortran-level executable parser.

## Strengths

The pinned StandardIR carries J3 document hash, rule, page, byte span and
structured RHS data. All four generated formats carry source lineage and
separate source and target expression hashes. Duplicate source occurrences
remain visible in lineage. ANTLR4, Bison and tree-sitter accept the generated
targets, and the negative mutation is rejected. Generated helpers visibly use
source-expression-sha256=none with a separate target hash.

These are genuine StandardIR advantages: normative provenance, duplicate
occurrence lineage and one source projected to four formats. They are not
claims of parser equivalence.

## Defects

The independent identity gate fails in every format: 1,068 source alternatives
are expected, 1,053 are covered, and 92 rows are missing or wrong. Eight
Unicode-bearing rows have wrong source hashes. Source alternatives disappear
into generated helpers or transformed bodies, including R401--R403 and the
additional transformed cases listed by the identity report. Nullable-reference
normalization changes visible source structure for R1404/R1416 without an
independent language-preservation witness. The selected profile omits six
declared roots. The run metadata also labels 522 syntax records as
source-alternatives even though the independent denominator is 1,068.

The raw-source/target-identity diagnosis is correct: the closure path hashes
after lexical canonicalization, so the standalone UTF-8 test did not cover the
actual adapter boundary.

## Required gates

Before claiming faithful StandardIR projection, capture raw source RHS identity
before lexical or target normalization; cover every source alternative in all
four formats; preserve typed lineage through helpers, factoring and merges;
independently witness any source-visible normalization; and close selected
profile, lexical and corpus coverage.

Before claiming LFortran-level parser quality, add an executable lexer/runtime
ABI, typed semantic values, precedence and associativity, AST/trivia actions or
an equivalent target contract, generic role factoring, explicit conflict
policy, and positive/negative language-corpus evidence. The current Bison
target still reports 427 shift/reduce and 2,266 reduce/reduce conflicts.

The reference remains comparison evidence. Its executable parser properties
are genuine reference advantages, while StandardIR's provenance properties
remain genuine StandardIR advantages. No reference production should be
copied into StandardIR.

Evidence: E0154/R000311 and the files under .cache/runs/E0154/R000003.
