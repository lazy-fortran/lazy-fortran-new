# E0071 report

All values and evidence tables below are regenerated by
`research/experiments/E0071-can-source-controlled-adjudication-separ/analyse.sh`.
The analyzer is pinned to `lazy-fortran-new` commit `5becfb3`, and the run
makes no experimental model calls.

## Question

Can source-controlled adjudication separate normative relations from
bounded-prose false positives?

## Method

The analysis reruns E0070 and preserves its complete 42-span candidate
inventory. The adjudication oracle records one disposition for every span:
`accepted` with a D0019 resolution class and target, or `retained` when the
candidate occurrence does not define the unresolved term. Every row retains
the E0070 source line and page, the J3/24-007 source hash, a source reference,
and an evidence phrase.

The gate checks the evidence phrase against both the candidate source text and
a separately normalized traversal of the canonical document. A second count
traversal independently reproduces the disposition totals. The source phrase
for one accepted relation is then mutated and must disappear. No candidate is
projected into a parser by this experiment.

The five retained records are `type-name` in a non-definitional name
occurrence, `submodule-name` in an identity constraint, `.LT.` in a
defined-operator list, `generic-name` in a grammar alternative, and a
`procedure-name` occurrence in general interface prose. They remain residue;
the spelling of a term never upgrades them.

The 37 accepted rows are source-controlled evidence records, not yet a
complete parser projection. They establish that E0070's broad inventory can
be reduced mechanically to a smaller typed source set while preserving the
false-positive denominator.
