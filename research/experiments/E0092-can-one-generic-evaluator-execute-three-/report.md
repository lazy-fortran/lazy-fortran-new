## Question

Can one generic evaluator execute three accepted StandardIR predicate forms
without rule-specific branches, and retain source-linked diagnostics?

## Method

The analyzer reruns E0090 and selects C601, C603 and C719 from its generated
semantic rule table. It checks their predicates, fact fields, source locations,
source hashes, source evidence and origins against a separately maintained
target oracle. The generated evaluator dispatches on the predicate constructors
`le`, `ge`, and `exists`/`ne`. It contains no selected constraint IDs.

The six witnesses cover one positive and one negative source for each rule:
name length, label digits and integer kind. GNU Fortran independently checks
the same sources. A separate witness oracle fixes the expected statuses and
source shapes. A predicate mutation is a negative control.
