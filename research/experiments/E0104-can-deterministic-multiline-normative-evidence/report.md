## Question and method

E0104 extends the E0100 lexical inventory over its 127-row residue (46 ambiguous and 81 no-candidate rows). It searches only physical adjacent lines, bounded three-line windows, and sentence continuations. A generic normative cue (`is`, `means`, `shall`, `must`, `may`, and a small fixed set of equivalent prose cues) must occur in the same bounded window. Each hit retains the exact joined source text, physical line range, page range, J3/24-007 SHA-256, and `MECHANICAL` origin.

## Limitations

This is evidence retrieval, not semantic adjudication. It does not infer suffix conventions, recognize Fortran rule identifiers, copy comparison grammars, promote aliases, or call a model. The first Fortran-specific point would be adding knowledge that a token such as `-list` or `-name` is a grammar-category convention, or interpreting a rule reference as a production definition; both are explicitly outside this experiment. Generic words such as `is` and `shall` can occur in unrelated prose, so a future wider window would increase false positives unless it adds a separately justified source-structure oracle.
