# E0070 report

All values and evidence tables below are regenerated by
`research/experiments/E0070-can-bounded-sentence-and-table-structure/analyse.sh`.
The recognizer is pinned to `lazy-fortran-new` commit `a2ac480`, the canonical
text and E0022 audit are pinned by SHA-256, and the run makes no model calls.

## Question

Can bounded sentence and table structure recover additional normative
relations mechanically from the 181-name E0022 unresolved denominator?

## Method

The analysis first builds bounded logical units from the canonical text. It
joins lines only within a numbered paragraph and flushes at a new paragraph,
blank line, page boundary, or table boundary. It retains table rows only
between an explicit table header and the next numbered paragraph. The source
page, canonical line span, and source hash are carried into every candidate.

The recognizer then checks lexical-class definitions, the known `xyz`
metavariable form, direct aliases, and bounded name-role sentences. A separate
audit-driven traversal recomputes the candidate term/kind set from the emitted
units. Fixed witnesses cover cross-line `entry-name` and `result-name` name
relations, a punctuation table row, the predecessor `digit` definition, and a
negative `program-name` constraint. A controlled mutation removes the table
witness and must fail the gate.

Candidates are evidence records only. This experiment does not accept a
candidate as a StandardIR fact, alter the parser projection, or call a model.

The bounded pass increases the measured candidate inventory from 7 to 30
names, but it does not establish that all 30 are valid definitions. In
particular, the candidate inventory includes evidence from syntax-adjacent
sentences and table rows; source-controlled adjudication is still required
before projection. The 151-name residue is retained for the next resolution
stage.

## Boundary

The result supports sentence structure and table extraction as useful
mechanical preprocessing. It does not justify suffix inference, automatic
StandardIR acceptance, or immediate model escalation for every candidate. The
next slice should independently adjudicate the source-linked candidates and
measure how many are genuine typed relations before exposing the remaining
residue to a model.
