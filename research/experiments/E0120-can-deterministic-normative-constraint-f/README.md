# E0120: deterministic normative constraint-form extraction

Question: can deterministic normative constraint-form extraction expand the
independent source-oracle coverage beyond the eight exact E0083 rows, without
model calls or candidate-specific branches?

Run the experiment with:

```sh
research/experiments/E0120-can-deterministic-normative-constraint-f/analyse.sh
```

The command reads the pinned canonical text, page index, E0081 constraint
inventory, E0106 structure artifacts and E0083 independent oracle. It writes
ignored run summaries under `.cache/runs/E0120/R000001` and regenerates the
committed [`source-oracle.tsv`](source-oracle.tsv). The table is emitted by
`analyze.py`; it is not a copied model or policy table. Every accepted row has
`MECHANICAL` origin, a canonical byte span, a page-index page, its C/R identity,
the source document hash and a normalized predicate.

The analyzer recognizes only complete, unambiguous generic sentence forms:
bounded inequalities, finite membership, implication, conjunction/type
membership, presence/absence, exclusion and cardinality. It retains all 287
inventory rows in `classifications.tsv` with `accepted`, `ambiguous`,
`unsupported` or `no-match` status. It has no model or compiler calls.

The current run of the command above reports 23 accepted records: the eight
E0083 baseline rows plus 15 expanded rows. It retains 258 unsupported, six
no-match and zero ambiguous rows; all eight baseline predicates match. These
counts are regenerated by the command and are not a hand-maintained result
table.

Run the focused behavioral and falsifying checks with:

```sh
research/experiments/E0120-can-deterministic-normative-constraint-f/selftest.sh
```

The selftest checks the positive expansion and requires rejection of mutated
source bytes, an inventory source hash and bytes, and an E0083 predicate.
Regenerate the numbers beside the command above; no counts are maintained
manually here.

Limitations: this is sentence-form extraction, not a Fortran semantic parser.
Compound clauses, cross-sentence references, prose with unresolved domain
terms and patterns whose normalized relation is not determined by the wording
remain unsupported or no-match. The E0083 table is an independent baseline,
not a source for new rows. A positive expansion does not establish that the
new predicates are sufficient for StandardIR acceptance.
