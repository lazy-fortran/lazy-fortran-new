## Question

Can deterministic predicate patterns formalize a bounded Core 0 constraint set
with source provenance and dependency facts?

## Method

The analyzer reruns the E0081 inventory over the pinned J3/24-007 canonical
text. It matches eight predeclared, single-sentence constraint witnesses. Each
match receives a predicate form, subject, applicability, required facts,
provided facts and normalized predicate. The other 279 constraints remain
`unresolved` with no predicate.

The source-linked formalizations retain the standard hash and source text. A
separate oracle table checks the selected IDs, source phrases, predicates and
fact sets. Required facts and provided facts produce a dependency graph. A
deterministic topological traversal checks the order against every edge. Source
and predicate mutations are required to fail.

## Boundary

explicit fact dependencies. The dependency graph is derived from records and
is not a manually maintained pass list. The next slice should expand the
mechanical vocabulary over a predeclared set of constraints that require

escalation remains deferred until that broader deterministic boundary is
