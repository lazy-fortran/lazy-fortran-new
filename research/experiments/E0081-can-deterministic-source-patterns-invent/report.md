## Question

Can deterministic source patterns inventory semantic relation and constraint
candidates before formalization?

## Method

The analysis retains the complete 181-name unresolved-reference denominator
from E0022. It scans the pinned canonical text for exact lexical/metanotation
definitions, same-line relations, and modal `shall`/`must` constraint
candidates. A candidate is a source span, not an accepted StandardIR fact.

Separately, it extracts every numbered C-rule line that names at least one
R-rule in the pinned 345-member E0014 Core 0 syntax closure. Each record keeps
the C identifier, associated Core 0 R-rules, canonical line, derived page and
source hash. The independent traversals recompute both candidate sets, and a
controlled change to the `program-name` modal wording must remove its candidate.

it does not claim that every same-line occurrence is a complete formal rule.

escalation remains deferred until that deterministic adjudication is measured.
