# E0160 plan

E0159 identified the selected role/name-family conflict family as the largest
structural reduce/reduce category, but it did not justify a grammar rewrite.
E0160 tests the already accepted generic role-family mechanism as an explicit,
opt-in target projection. The default source-backed export remains unchanged.

The first required production slice is a deterministic CLI/configuration hook
for selecting a representative family. After that hook is merged and pinned,
the laboratory will run baseline and opt-in selected/all-root replays through
the same source preflight, source identity, lexical, four-format and parser
oracles. A lower Bison count is not a success unless source roles, provenance,
and an independent bounded accepted language are preserved.
