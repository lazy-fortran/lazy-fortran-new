## Question

Can the 178-name post-alias residue be classified without guessing parser
aliases?

## Method

The analysis reruns E0074 and E0072, verifies their integrated syntax and
composite-fact hashes, and extracts the unique references that still have no
lhs production. It joins those names to existing source-provenanced facts,
using the strongest existing class where a term has more than one fact. It
does not create a new fact and does not add a parser alias.

The class join is independently counted and source-checked. A semantic-role to
alias mutation must fail the class gate.
